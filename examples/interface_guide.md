# Interactive Prediction Interface

To run the interactive UI in a local or Colab environment, execute the `tennis_model_v3.py` script or use the provided Jupyter notebook snippets.

### Features:
- **Searchable Player Fields**: Filter through 50,000+ players.
- **Automatic Context Detection**: If a match is scheduled for Roland Garros 2026, the UI automatically sets the surface to Clay.
- **Confidence Visualization**: Provides a percentage-based reliability score.
